# CCNA-Study-Review
A 34-page document that I created while studying to take the CCNA exam. 

This document includes notes, tables, and key details that I wanted to memorize and reinforce before taking the exam. This guide is intended for review and should be used AFTER studying and understanding the foundational CCNA concepts. Personally, I reviewed this document and practiced active recall every day during the final month leading up to my exam. I recommend using this document alongside Jeremy's IT Lab's Anki flashcards and Boson ExSim practice exams for additional review and practice.

Both DOCX and PDF versions are included. Feel free to edit the DOCX version and add your own notes as you study.

Material in this document was compiled from my personal study notes and references information covered in Jeremy's IT Lab videos and Cisco documentation.

DISCLAIMER: This is NOT an official Cisco study guide. This document represents my personal study notes and was created as a review resource based on my own preparation for the CCNA exam. It is not affiliated with or endorsed by Cisco, Jeremy's IT Lab, or Boson.
