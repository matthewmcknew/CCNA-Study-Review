# CCNA-Study-Review
A 34-page document that I created while studying to take the CCNA exam. 

This document includes notes and tables for concepts and details that I needed to memorize. The reader should only use this guide for review AFTER studying the foundational concepts. Personally, I read through this document and performed active recall every day for the last month leading up to my exam date. I recommend using this document in combination with Jeremy's IT Lab's Anki flashcards and Boson ExSim practice exams for review.

I have attached Word Document as well as PDF versions. Feel free to make any edits or add your own notes to review.

Material in this document references a mix of notes from Jeremy's IT Lab videos, as well as information that can be found on Cisco.com.

DISCLAIMER: This is NOT an official Cisco study guide.
